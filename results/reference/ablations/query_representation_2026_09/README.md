# Query representation experiment — 2026-09

This directory is generated by `scripts/experiments/collect_query_representation.py`.

Scientific question: should a CpG query RNA program tokens using the generic frozen NTv3
embedding or a methylation-aware locus representation learned through the mean-proxy task?

Controlled arms:

- `q0_ntv3`: `q = W_e e_c` (current reference).
- `q1_mean_only`: `q = W_mu h_mean`.
- `q2_hybrid_detached`: `q = W_e e_c + W_mu stopgrad(h_mean)`.
- `q3_hybrid_joint`: `q = W_e e_c + W_mu h_mean`.

For Q2/Q3, `W_mu` is zero-initialized, so both start exactly from the current NTv3 query and
must learn to use the mean-aware representation. Q2 isolates representation reuse without
letting the RNA-prediction loss reshape `h_mean`; Q3 allows joint co-adaptation.

Selection is performed only on a fixed **development** split. The official MethylProphet held-out
split is not touched during architecture selection. `summary.yaml`/`summary.md` are therefore
ablation evidence, not headline paper test numbers. The selected query must be retrained once in
`mode=final` and then confirmed across seeds/fresh scope.
